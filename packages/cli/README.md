# logic-map

Turn a TypeScript or JavaScript codebase into an evidence-backed interactive logic map.

```bash
npx logic-map@latest .
```

The command analyzes the selected project, writes `.logic-map/graph.json`, starts a local viewer, and opens it in the browser. Analysis is local and no source code is uploaded.

Use `logic-map analyze .` to generate JSON without starting a server. See the [project repository](https://github.com/tangyishun9846/logic-map) for supported frameworks, limitations, privacy behavior, and contribution guidelines.
