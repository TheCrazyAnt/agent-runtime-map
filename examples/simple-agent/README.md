# Simple Content Agent

This example turns a user brief into publishable content and keeps every step inspectable.

## Content Generation

Generate ideas, create a story, build a script, and save the resulting content.

## Draft Review

Score a draft and branch into approval, revision, or rejection before returning a decision.

## Knowledge Import

Parse an uploaded document, index its knowledge, and persist the document for later Agent use.

## Publishing

Publish an approved draft. The example intentionally leaves this route disconnected so Chain Doctor can demonstrate a red failure.
